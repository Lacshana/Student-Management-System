# Student Management System (C++)

## Project Description / Purpose
A console-based application developed to manage student details and academic records efficiently[span_0](start_span)[span_0](end_span). The purpose of this project is to apply Object-Oriented Programming (OOP) concepts in C++—specifically focusing on how constructors, default constructors, and destructors manage object initialization and memory cleanup during runtime.

## Technologies Used
* **Language:** C++[span_1](start_span)[span_1](end_span)
* **Concepts Applied:** Object-Oriented Programming, Classes and Objects, Default Constructors, Parameterized Constructors, and Destructors.

## Features
* **Add Student Details:** Create new student records dynamically using parameterized constructors.
* **Default Initialization:** Set up baseline default values for new student objects automatically using default constructors.
* **View Student Records:** Display stored student details cleanly on the console.
* **Automatic Cleanup:** Handle memory management and object destruction safely using destructors when records go out of scope.

## What I Learned
* Gained a solid understanding of C++ programming logic and object lifecycle management.
* Learned how default constructors and destructors work under the hood to allocate and release resources.
* Practiced structuring files, debugging code, and organizing a complete C++ mini-project for a Github portfolio
